Bencris mobile

The three Flutter apps, built and served from this container. On a phone, reach this page at the laptop's network address rather than localhost, which on a phone means the phone itself.

Bencris
Order from the live menu and hold your ticket. No account needed.
Bencris Counter
Look up a ticket, check the payment, settle it.
Bencris Operations
Sales, kitchen queue, stock, menu and payments.
All three read the hosted Supabase project, the same database the web app uses. The data never comes from this machine, so once these files are deployed a phone no longer needs to be on this network at all.

Installing to the home screen needs HTTPS, which a plain address on the local network cannot offer, so browsers will refuse it here and give a bookmark instead. Served over HTTPS the same files install properly, with no change to the build.
